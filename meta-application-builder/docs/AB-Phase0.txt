### 2. Pydantic Types & Core Method Interfaces

#### `security_context/claims.py`

```python
from typing import List, Optional
from pydantic import BaseModel, Field, HttpUrl, field_validator

class SecurityClaims(BaseModel):
    iss: str = Field(..., description="Issuer authority URI")
    sub: str = Field(..., description="Subject identity ID")
    aud: str = Field(..., description="Audience target")
    exp: int = Field(..., description="Expiration timestamp (Unix Epoch)")
    nbf: int = Field(..., description="Not-before timestamp (Unix Epoch)")
    iat: int = Field(..., description="Issued-at timestamp (Unix Epoch)")
    jti: str = Field(..., description="Unique JWT Identifier")
    tenant_id: str = Field(..., description="Tenant namespace identifier")
    roles: List[str] = Field(default_factory=list, description="Assigned RBAC roles")
    permissions: List[str] = Field(default_factory=list, description="Fine-grained ABAC permissions")

    @field_validator("tenant_id")
    def validate_tenant_format(cls, v: str) -> str:
        if not v.startswith("tenant_") or len(v) < 8:
            raise ValueError("Tenant ID must follow standard namespace format 'tenant_<name>'")
        return v

```

class IdentityContextManager:
    """Manages thread-local and async-task safe workload identity context propagation."""

    @staticmethod
    def set_current_identity(claims: SecurityClaims) -> contextvars.Token:
        """Sets the validated identity context for the active async task execution chain."""
        return _SECURITY_CONTEXT.set(claims)

### 3. Edge Cases, Failure Modes & Performance Trade-offs

* **Context Leakage across Async Tasks (Edge Case):** In Python `asyncio`, tasks inherit `ContextVar` context copies. Mutating an inherited mutable payload alters task state.
*Mitigation:* `SecurityClaims` is strictly frozen/immutable. Restoring context tokens via `reset_identity()` in generic API middleware guarantees task cleanup.
* **Clock Skew in JWT Verification (Failure Mode):** Distributed microservices experience minor clock drift, failing strictly bounded `nbf` and `exp` validations.
*Mitigation:* Enforce a strict **60-second leeway** window in public key JWT decoding passes.
* **OPA Sidecar Network Latency (Performance Trade-off):** Fetching HTTP policy decisions per boundary evaluation adds sub-10ms network overhead per request.
*Trade-off Decision:* Retain HTTP sidecar in Phase 0 for physical separation; transition to in-memory PyOPA bindings or local Unix domain sockets in high-throughput pipelines.
