### Control Plane Architecture

To allow autonomous triage agents to act as first-class operators over the execution fabric, we expose control plane operations via an idempotent, capability-bounded tool interface. The agent operates within a closed-loop controller (Sense-Plan-Act-Verify) backed by distributed state machine snapshots.

### Agent Tool Contracts

| Tool Name | Parameters | Capabilities & Guardrails |
| --- | --- | --- |
| `inspect_manifest` | `run_id`, `step_id`, `depth` | Reads active graph state, node input/output artifacts, execution logs, and runtime telemetry. Read-only, zero latency impact. |
| `retry_step` | `run_id`, `step_id`, `override_config` | Triggers isolated step execution with patched parameters (e.g., adjusted memory allocations, modified timeout bounds). Idempotency key required. |
| `replan_dag` | `run_id`, `failed_step_id`, `mutation_spec` | Prunes dead branches, injects fallback nodes, or dynamically updates dependencies without invalidating upstream completed state. |

### Self-Healing & Operational Triage Loop

The agent loop intercepts runtime failures via a pub/sub event handler (`WorkflowStepFailed`) and executes four operational phases:

1. **Telemetry & Manifest Context Gathering**
* The triage agent calls `inspect_manifest` to pull execution context, stack trace, resource utilization metrics, and upstream dependency metadata.


2. **Failure Classification & Root-Cause Diagnosis**
* *Transient Infrastructure Error* (e.g., OOM, network timeout): Route to parameter mutation.
* *Deterministic Data Error* (e.g., schema mismatch, invalid spatial asset): Route to DAG replanning.
* *Unrecoverable Invariant Violation* (e.g., missing security context): Route to human escalation.


3. **Action Execution**
* **Localized Repair:** Issues `retry_step` with tuned hyperparameters (e.g., doubling memory limits or switching compute target from CPU to GPU).
* **Graph Mutation:** Issues `replan_dag` to inject an alternative asset-baking node or bypass non-critical visualization steps.


4. **Post-Action Verification & Feedback Sync**
* Monitors step recovery over an execution window. If the mutation succeeds, update global hyperparameter heuristics in the shared control plane cache.



### Automated Escalation & Parameter Tuning Matrix

| Failure Mode | Autonomous Remediation Strategy | Escalation Threshold |
| --- | --- | --- |
| **OOM / Out of Resource** | Step Retry with $1.5\times$ RAM/VRAM allocation via `override_config`. | Max 2 retries; escalate to DevOps on 3rd failure. |
| **Stale / Corrupted Dependency** | DAG Replan: Insert dynamic validation/re-fetch node upstream. | Escalate if dynamic patch exceeds max runtime budget ($>300\text{s}$). |
| **Non-Convergent Optimization** | Parameter Tuning: Decay learning rate / adjust solver tolerance vectors. | Max 3 tuning iterations before flagging model drift. |
| **Permission / Auth Failure** | **No Retry.** Immediate escalation. | Instant notification to Ops with token diagnostic context. |

### `src/meta_control_plane/api/`

* `schemas/meta_mutation_schemas.py`: Schema definitions validating `mutation_spec` modifications to DAG graphs.

* `diagnosis/meta_failure_classifier.py`: Classifies errors into transient infrastructure, deterministic data, or unrecoverable invariant violations.

* `tools/meta_inspect_tool.py`: Agent wrapper for invoking graph and telemetry inspection capabilities.


* `tools/meta_retry_tool.py`: Agent wrapper for executing parameter overrides on isolated step retries.

For the `meta_control_plane` architecture, the technological stack is selected to prioritize sub-millisecond async event handling, strict schema validation, deterministic state machine mutations, and capability-bounded tool governance.

**Core Stack & Package Management**

* **Package & Environment Manager (`uv`)**: Leveraged for workspace management, lockfile generation (`uv.lock`), fast dependency resolution, and virtualenv execution (`uv run pytest`, `uv pip sync`).
* **Runtime Environment**: Python 3.12+ for native typing, async performance improvements, and structured concurrency support via `asyncio`.

**API & Schema Layer**

* **FastAPI**: Provides high-throughput async REST endpoints (`meta_manifest_api`, `meta_execution_api`, `meta_graph_api`) for control plane RPC operations.


* **Pydantic v2**: Handles strict schema validation for agent tool definitions (`meta_tool_schemas`) and JSON mutation payloads (`meta_mutation_schemas`), utilizing Rust-backed validation.



**Eventing, Cache & Persistence**

| Component | Technology | Purpose in Control Plane |
| --- | --- | --- |
| **Event Bus** | **Redis Pub/Sub** / **NATS Streaming** | Low-latency ingestion of `WorkflowStepFailed` system events into `meta_event_consumers`.

 |
| **Idempotency & Cache** | **Redis (via `redis-py` async)** | Stores idempotency keys for `retry_step`, lock distribution, and dynamic hyperparameter heuristics in `meta_heuristic_cache`.

 |
| **State Storage** | **PostgreSQL** + **SQLAlchemy 2.0 (Async)** | Stores persistent DAG snapshots, run histories, node artifact metadata, and telemetry logs. |
