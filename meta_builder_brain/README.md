# Meta-Builder Brain

Production-grade engine for dynamic schema synthesis, multi-tenant namespace resolution, policy guardrails, and dynamic SQLAlchemy ORM compilation.

## Project Layout
- `src/meta_builder_brain/`: Primary Python application package.
- `docker/`: Docker container configs and OPA sidecar definitions.
- `tests/`: Unit and integration testing suites.
- `docker-compose.yml`: Multi-container orchestration mesh.
