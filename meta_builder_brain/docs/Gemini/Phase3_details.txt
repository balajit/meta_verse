Phase 3

### Goal:Automate schema and workflow generation from input schemas, raw documents, RFCs, and text instructions.

### Detailed Design

### 1. Ingestion & Normalization Worker

    FastAPI Ingestion Gateway:** An asynchronous API entry point receiving raw RFC payloads and standard documents from the Spec & RFC Ingestion Bus. This service handles webhook events from upstream portals and delegates processing to async worker queues.
    Playwright Scraping Engine:** A containerized headless browser pool executing extraction scripts to scrape dynamic standards portals. It isolates raw DOM content and normalizes it into standardized HTML blocks.
    Document Partitioning Pipeline:** Integrates PyMuPDF for structural PDF merging and Docling to partition complex tables and unstructured text into clean, hierarchical markdown trees.

### 2. LLM Orchestrator & Synthesis Engine

    gent Harness & MCP Integration:** Utilizes a single-agent architecture (e.g., the Hermes Agent Framework) integrated with the Model Context Protocol (MCP) to dynamically fetch necessary sub-schemas during the generation pass.
    Concurrency Controller:** Employs `asyncio` semaphores to tightly manage the thinking budget and rate-limit concurrent outbound requests to LLM endpoints.
    Structured Generation:** Interfaces with models like Qwen or Claude via the Anthropic SDK, enforcing explicit JSON schema generation to guarantee syntactically valid YAML/JSON outputs.


### 3. Dynamic Validation & Policy Guardrails

    Pydantic Retry Loop:** Maps generated JSON directly against strongly-typed Pydantic validation models. Any schema validation failure automatically synthesizes a correction prompt, feeding the exact error trace back to the LLM for resolution.
    OPA Sidecar Service:** Deploys an Open Policy Agent (OPA) sidecar operating as a localized container to intercept all validation requests prior to namespace registration.
    Rego Policy Evaluator:** Executes custom Rego logic to evaluate structural decisions, ensuring synthesized FSM lifecycle definitions and inheritance graphs do not illegally overwrite global base attributes.



### 4. Meta-Runtime Storage & Configuration

    Metaclass Schema Compiler:** Leverages custom Python metaclass ORM structures and strict SQLAlchemy naming conventions to handle dynamic database migrations and store compiled task graphs.
    OpenBao Secrets Manager:** A dedicated OpenBao server container handling all runtime credential provisioning, securing database authentication tokens and external API keys.
    Docker Compose Mesh:** Orchestrates the multi-stage pipeline, linking the ingestion services, OPA sidecars, PostgreSQL instances, and MinIO storage into a cohesive deployment environment.
